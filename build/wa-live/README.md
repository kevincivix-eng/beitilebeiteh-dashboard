# איסוף חי מקבוצות הוואטסאפ

אוסף את ההודעות ברגע שהן נשלחות, במקום לייצא את הצ'אט פעם בשבוע.

## למה לא מספיק ייצוא

| | ייצוא שבועי | איסוף חי |
|---|---|---|
| פרסום שנמחק אחרי מסירה | **אבוד** | נשמר, והמחיקה נרשמת בנפרד |
| כמה אחורה מגיע | ~1,000 הודעות עם מדיה | הכול, מרגע החיבור |
| הצטרפויות ועזיבות | מכווץ ל"ועוד 137 יצאו" | כל אירוע בנפרד, עם תאריך |
| ידיים | מישהי מייצאת כל שבוע | אפס |

**המחיקות הן הסיבה העיקרית.** בקבוצות האלה מוחקים פרסום ברגע שהחפץ נמסר — כלומר
דווקא המסירות שהצלחנו הן אלה שנעלמות מהייצוא.

## איך זה בנוי

- **הכול נכתב פעם אחת ולא נערך.** הודעה נשמרת לדיסק תוך שנייה מרגע שהגיעה, והמדיה
  יורדת מיד. מחיקה מאוחרת נרשמת כאירוע **לצד** הפרסום — הפרסום עצמו לא נמחק.
- **מספרי טלפון לא נשמרים בכלל.** הם מוחלפים ב-`[טלפון]`, ובמקומם נשמר גיבוב עם
  מלח מקומי. אותו מספר נותן אותו גיבוב, אז איחוד הכפילויות עדיין עובד, אבל מהגיבוב
  אי אפשר לחזור למספר.
- **קריאה בלבד.** מתחבר כמכשיר מקושר (כמו WhatsApp Web), לא מסמן הודעות כנקראות
  ולא מופיע מחובר.
- **קבוצות מזוהות לפי השם** (`من بيتي لبيتك`), אז קבוצה חדשה נקלטת בלי שינוי קוד.

## איפה יושבים הנתונים

`$WA_DATA_DIR` (ברירת מחדל `~/wa-live-data`), **מחוץ לריפו** — יש בו טקסט גולמי
ותמונות, והוא לעולם לא מגיע לגיטהאב.

```
messages/<group>/<YYYY-MM-DD>.jsonl   הודעה לשורה
events/<YYYY-MM-DD>.jsonl             מחיקות, הצטרפויות, עזיבות
media/<sha256>.jpg                    תמונה נשמרת פעם אחת גם אם הועברה ל-6 קבוצות
state.json                            דופק: מתי נשמע לאחרונה
auth/                                 מפתחות החיבור — לא לשתף
```

## הרצה

```bash
npm install
node collector.js        # בפעם הראשונה: סריקת QR מהטלפון
node status.js           # מה נאסף, ומתי נשמע דופק אחרון
```

בטלפון (Termux), דרך הסקריפט שמרים מחדש אחרי קריסה:

```bash
WA_DATA_DIR=~/wa-data ./run.sh
```

## הגדרות הטלפון (סמסונג — חובה)

סמסונג אגרסיבית בסגירת תהליכי רקע. פעם אחת:

1. **סוללה ← הגבלות שימוש ברקע:** Termux ו-WhatsApp מוגדרים "ללא הגבלה", ושניהם
   ברשימת "לעולם לא להרדים". לכבות "הרדמת אפליקציות שלא בשימוש".
2. **טיפול במכשיר:** לכבות אופטימיזציה אוטומטית והפעלה מחדש לילית.
3. **הגנה על הסוללה (85%)** — הטלפון בטעינה קבועה, וזה מונע נפיחות.
4. **Termux:Boot** מותקן ונפתח פעם אחת, כדי שהאיסוף יעלה לבד אחרי הפעלה מחדש.

גם עם כל אלה אנדרואיד יהרוג תהליך מתישהו — בשביל זה `run.sh` מרים אותו מחדש,
ו-`status.js` מראה אם הדופק נעצר.

## מה שחשוב לדעת

- **המכשיר המקושר מתנתק אם הטלפון לא עולה לרשת כשבועיים.** הטלפון דולק על וויפי,
  אז זה לא אמור לקרות.
- **זה לא ממשק רשמי של וואטסאפ.** המספר הוא מספר נפרד שנועד לזה; אם ייחסם, המיזם
  לא נפגע ואפשר לחזור לייצוא ידני. הנתונים שכבר נאספו נשמרים.
- **לא לשלוח הודעות מהחשבון הזה דרך הכלי.** קריאה בלבד היא מה שמשאיר את הסיכון נמוך.
